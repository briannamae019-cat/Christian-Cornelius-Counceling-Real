# Cornelius Christian Counseling — website concept

A responsive, single-page website concept for Cornelius Christian Counseling. Built with plain HTML, CSS, and JavaScript so it can be edited directly in Visual Studio Code without a build step.

## Preview locally

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension and select **Go Live**.
3. The page uses Google Fonts, which need an internet connection. Homepage photography is stored locally in `assets/`.

## Before publishing — replace the placeholders

Search the project for `ADD-` and `[Add` / `[Practice` to update:

- Practice email and phone number (including the `mailto:` and `tel:` links)
- Office location or service area
- Clinician name, professional license, education, certifications, experience, and specialties
- Actual services offered, intake process, session format, fees, privacy policy, and accessibility information

The service descriptions and FAQ content are starter copy and should be checked against the practice's actual offerings and professional requirements. Do not publish the credential placeholder as written.

## Notes

- Mobile navigation includes keyboard support and closes after a link is selected.
- Scroll reveals and the floating detail are intentionally subtle.
- `prefers-reduced-motion` is respected for visitors who have reduced motion enabled.
- No form or scheduling backend is connected. Add a secure, privacy-appropriate contact/scheduling provider before collecting client information. Avoid collecting sensitive details through an ordinary website form.
- The word **Counseling** is spelled correctly in the visible brand text.
